# 무료 글꼴 모음 — 라이선스

이미지 스튜디오(블로그 이미지 제작 · 배너 스튜디오 · 이미지 소스)가 피그마에서 가져온 글자를 같은 글꼴로 그리기 위해 함께 배포한다.
모두 상업적 사용이 가능한 무료 글꼴이다. 다시 만들 때는 `python3 tools/fonts-build.py <패키지 폴더>` (스크립트 상단 설명 참고).

| 글꼴 | 폴더 | 출처(npm) | 라이선스 |
|---|---|---|---|
| Noto Sans KR · Nanum Gothic · Nanum Myeongjo · Nanum Pen Script · IBM Plex Sans KR · Gothic A1 · Black Han Sans · Do Hyeon · Jua · Gowun Dodum · Gowun Batang · Song Myung · Inter · Roboto · Montserrat · Poppins | 각 이름 폴더 | @fontsource/* | SIL OFL 1.1 |
| SUIT | suit | @sun-typeface/suit | SIL OFL 1.1 |
| Spoqa Han Sans Neo | spoqa-han-sans-neo | spoqa-han-sans | SIL OFL 1.1 |
| Wanted Sans | wanted-sans | wanted-sans | SIL OFL 1.1 |
| NanumSquare Neo | nanum-square-neo | typeface-nanum-square-neo | SIL OFL 1.1 (네이버 나눔글꼴) |
| Gmarket Sans (Medium) | gmarket-sans | @noonnu/gmarket-sans-medium | G마켓 무료 글꼴 — 상업적 사용 가능, 글꼴 파일 판매 금지 |
| 잘난체 (Jalnan Gothic) | jalnan-gothic | 기존 블로그 이미지 제작 동봉본 | 여기어때 무료 글꼴 — 상업적 사용 가능, 글꼴 파일 판매 금지 |
| 에스코어드림 · 프리텐다드 | banner_studio/fonts | 기존 동봉본 | 에스코어 무료 글꼴 · SIL OFL 1.1 |

피그마의 SF Pro(아이폰 화면 글꼴)는 애플 라이선스상 배포할 수 없어 시스템 글꼴(맥에서는 SF Pro 그대로, 윈도우에서는 Inter)로 그린다.
