🎨 피그마에서 가져오기

프레임 링크를 넣으면 텍스트·도형·그라데이션·이미지 채우기·그림자·블러·테두리·오토 레이아웃 패딩을 편집 가능한 상태로 가져와. 아이콘·벡터처럼 직접 그릴 수 없는 것만 피그마가 그린 그림으로 받아.
링크 복사: 피그마에서 프레임 선택 → 우클릭 → 선택 항목 링크 복사 (Ctrl+L / ⌘L)
이 브라우저에 토큰 기억 (공용 PC 에서는 끄세요)
링크한 프레임 안의 프레임·컴포넌트를 각각 따로 저장 (페이지·섹션 링크는 자동)
플러그인이 만든 .json 파일을 여기에 끌어다 놓거나 클릭해서 선택
처음 한 번 플러그인 설치: 플러그인 받기(.zip) → 압축 풀기 → 피그마 데스크톱 앱 → Plugins → Development → Import plugin from manifest… → 풀린 image-studio-figma-plugin-v2 폴더 안의 manifest.json 선택 (예전 '이미지 스튜디오로 내보내기' 는 Manage plugins in development 에서 지워 주세요. 압축 푼 폴더는 지우거나 옮기지 마세요)
